# Construction Site Safety Object Detection using YOLO11

This project uses YOLO11n for object detection on a construction site safety dataset.

## Classes
- Hardhat
- Mask
- NO-Hardhat
- NO-Mask
- NO-Safety Vest
- Person
- Safety Cone
- Safety Vest
- Machinery
- Vehicle

## Project Workflow
- Dataset loading
- Data visualization
- Label preprocessing
- Fine-tuning YOLO11n
- Validation
- Testing
- Object detection with bounding boxes and confidence scores

## Technologies
- Python
- YOLO11
- PyTorch
- OpenCV
- Google Colab
- Matplotlib

## Dataset
Construction Site Safety Image Dataset from Kaggle.

## Output
The model detects safety-related objects and displays:
- Class name
- Confidence score
- Bounding box
